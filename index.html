Click any button to play a sound. Drag the slider to adjust volume.

How to Add Your Own Sounds:

1. Place your sound files in the same folder as this HTML file

2. Rename them to: sound1.mp3, sound2.mp3, etc.

3. Supported formats: MP3, WAV, OGG

4. Update button labels by changing the text inside the .sound-label span

5. Change icons by updating the FontAwesome class names
